# Artifact Library

Open **Artifacts** in the sidebar to search files explicitly delivered with DSH’s `present` tool. The library reads authorized session history without starting agents. Select a conversation filter or load older results. Open the source chat or add a file reference to its composer for follow-up work.

The library references the current file at its original path. It does not copy or upload files. Moved and deleted files may need to be recovered from the source project. Outputs mentioned only in prose do not appear.
