# Appshots

Select **Appshot** above a conversation’s composer. On macOS Desktop, **Capture window** opens the system window picker. Click a window to capture it or press Escape to cancel. Grant Screen Recording permission to DeepSeek Harness if macOS asks. In a supported browser, **Capture window or tab** uses the browser’s sharing picker and stops sharing after the first frame. **Open image** accepts PNG, JPEG, or WebP screenshots.

Drag to mark an area, optionally add a label, then select **Attach to draft**. DSH handles the PNG through its normal attachment flow. It can stage the image on the DSH Host as soon as you attach it. Your model receives the attachment when you send the draft.

The native picker is available to the local macOS Desktop interface. It uses the system screenshot utility and removes its temporary copy after reading the capture. If screen capture is unavailable, import an existing screenshot.
