# DSH Mac Video Use

Adds guidance for editing video through the native DSH `cua` tool. It covers focus, timecode, fresh timeline geometry, verification after edits, and export checks. The video guidance follows the general macOS guidance when both are installed.

Requires macOS and the DeepSeek Harness 0.2.2-rc.1 CUA bundle. Use DSH’s app approvals and macOS permissions. To verify against a specific editor, use a scratch timeline and synthetic clips. Check one reversible edit and verify a completed export to a temporary directory.
